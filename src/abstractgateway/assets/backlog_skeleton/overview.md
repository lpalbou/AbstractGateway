# Backlog Overview

This is the planning ledger for work tracked on this gateway. Each item is one Markdown file;
the folder it lives in is its state. AbstractContinuum's Board and Backlog pages read and write
these files through the gateway, and you can edit them with any text editor.

## Folders

- `proposed/` — ideas and requests waiting for triage (the Board's Triage column).
- `planned/` — accepted work, ready to be picked up or executed (the Board's Ready column).
- `completed/` — finished items, kept as the history of what was done and how it was verified.

## Operating Notes

- Start a new item from `template.md` (Continuum's **New task** does this for you).
- Name item files `NNNN_<slug>.md` with a four-digit id that is unique across the three folders.
- Moving an item between folders changes its state; keep this overview's tables in step.
